# PrecManager — Grupo Precision

Portal de entrega técnica de projetos de engenharia.

## Como rodar localmente
1. Instale as dependências: `npm install`
2. Inicie o servidor: `npm run dev`

## Deploy na Vercel
Suba os arquivos desta pasta para o repositório `precmanager` no GitHub (`fernando-precision-design`) e importe o projeto na Vercel.
